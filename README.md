# XR-Based Multilingual Language Learning System

## 📖 Overview
An immersive multilingual language learning system combining **Virtual Reality (VR)** and **Large Language Models (LLMs)** to enable natural language practice across English, Chinese, and Japanese.  
Developed for Meta Quest 2 using Unity.

## 🎯 Project Goals
- Create interactive 3D avatar for immersive conversation.
- Support multilingual real-time switching.
- Implement emotional AI dialogue powered by GPT-4.
- Prioritize cultural adaptation and user emotional engagement.

## 🛠️ Technology Stack
- Unity 2021+
- C#
- OpenAI GPT API
- Microsoft Azure Speech Services
- Meta Quest 2
- VRM and Oculus Integration SDKs

## 🚀 Features
- 🌏 English, Chinese, Japanese conversation modes.
- 🧠 Emotionally aware 3D AI avatar.
- 🎮 Voice input, real-time AI response, Text-to-Speech output.
- 🎥 Mixed Reality passthrough support.
- 🎯 Low-latency interaction and smooth UX.

## 📲 Try the APK Directly
